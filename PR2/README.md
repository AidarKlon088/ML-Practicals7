## Основной код

| Команда | Что делает |
|---|---|
| `df.info()` | Показывает структуру данных |
| `df.describe()` | Считает основные статистики |
| `df.isnull().sum()` | Ищет пропущенные значения |
| `df.duplicated().sum()` | Считает дубликаты |
| `value_counts()` | Показывает количество записей по жанрам |
| `sns.histplot()` | Строит распределение популярности |
| `sns.boxplot()` | Показывает потенциальные выбросы |
| `sns.scatterplot()` | Показывает связь двух признаков |
| `df.corr()` | Вычисляет корреляции |
| `sns.heatmap()` | Визуализирует корреляционную матрицу |
