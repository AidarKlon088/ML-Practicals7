# Практическая работа №3 — Предобработка данных

**Тема:** Подготовка данных для машинного обучения  
**Язык:** Python, Scikit-learn

## О проекте

Я использовал Spotify Dataset, чтобы подготовить числовые и категориальные признаки для обучения ML-моделей.

## Основной код

| Код | Для чего нужен |
|---|---|
| `train_test_split()` | Разделяет данные на train и test |
| `SimpleImputer()` | Заполняет пропущенные значения |
| `StandardScaler()` | Масштабирует числовые признаки |
| `OneHotEncoder()` | Преобразует жанры в числовые признаки |
| `ColumnTransformer()` | Применяет разные методы к разным столбцам |
| `Pipeline()` | Объединяет несколько этапов обработки |
| `fit_transform()` | Обучает преобразования и применяет их |
| `transform()` | Применяет уже обученные преобразования |

## Что я сделал

Выбрал характеристики музыки, разделил данные на обучающую и тестовую выборки и создал пайплайн предобработки.

**Важно:** пайплайн обучается только на train, чтобы избежать утечки информации из test.

## Запуск

1. Установить библиотеки: `pip install pandas numpy scipy scikit-learn jupyter`
2. Открыть `notebook.ipynb` в VS Code.
3. Нажать **Run All**.

Используется датасет `PR1/dataset.csv`.

## Результат

Получил обработанные числовые признаки и закодированные музыкальные жанры. Данные подготовлены для обучения моделей машинного обучения.
