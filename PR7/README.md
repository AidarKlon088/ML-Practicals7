# Практическая работа № 7. Случайный лес

Выполнил: Айдар Нурбекович

Цель: сравнить дерево решений и случайный лес для задачи классификации.

В работе используются предобработка данных, DecisionTreeClassifier, RandomForestClassifier, сравнение метрик Accuracy и F1, а также график важности признаков.

В случайном лесу используются 100 деревьев для повышения стабильности предсказаний.
