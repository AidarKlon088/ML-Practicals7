# Практическая работа №7 — Random Forest

**Тема:** Дерево решений и случайный лес  
**Датасет:** Spotify Tracks Dataset  
**Библиотеки:** Pandas, NumPy, Matplotlib, Scikit-learn

## О проекте

Я обучил две модели, чтобы определять популярные и непопулярные треки Spotify. Сравнил одиночное дерево решений со случайным лесом из 100 деревьев.

## Основной код

| Код | Что делает |
|---|---|
| `train_test_split()` | Делит данные на Train и Test |
| `SimpleImputer()` | Заполняет пропущенные значения |
| `OneHotEncoder()` | Кодирует музыкальные жанры |
| `Pipeline()` | Объединяет обработку и модель |
| `DecisionTreeClassifier()` | Обучает одно дерево решений |
| `RandomForestClassifier()` | Обучает ансамбль из 100 деревьев |
| `accuracy_score()` | Считает общую точность |
| `f1_score()` | Оценивает качество определения популярных треков |
| `feature_importances_` | Показывает важность признаков |

## Что я сделал

Обучил две модели на одинаковых данных, сравнил Accuracy и F1 и построил график важности признаков.
