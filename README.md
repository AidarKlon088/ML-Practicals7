# Практические работы по машинному обучению

**Выполнил:** Айдар Нурбекович

## О проекте

Этот репозиторий содержит 7 практических работ по машинному обучению на Python. В них рассматриваются анализ данных, подготовка данных для моделей, регрессия, классификация текстов и другие методы машинного обучения.

## Используемые технологии

- Python
- Jupyter Notebook
- Pandas и NumPy — работа с данными
- Matplotlib — построение графиков
- Scikit-learn — подготовка данных и обучение моделей

## Содержание практических работ

### PR1. Знакомство с Python и Jupyter Notebook

Знакомство с рабочей средой, загрузка и просмотр набора данных `tips.csv`. Изучение основных операций с таблицами.

### PR2. Исследовательский анализ данных (EDA)

Анализ набора данных `customers_dirty.csv`. Просмотр структуры данных, поиск пропусков и других проблем, построение графиков и формулирование выводов.

### PR3. Предобработка данных

Подготовка данных для машинного обучения. Числовые пропуски заполняются медианой, категориальные значения кодируются, числовые признаки масштабируются. Данные разделяются на обучающую и тестовую выборки.

### PR4. Регрессия

Обучение модели линейной регрессии для предсказания числового значения дохода. Оценка модели с помощью MAE, RMSE и R², анализ результатов и графиков.

### PR5. Бинарная классификация

Обучение логистической регрессии для разделения объектов на два класса. Оценка результатов с помощью Accuracy, Precision, Recall и F1, анализ матрицы ошибок.

### PR6. Классификация текстов

Сравнение CountVectorizer и TfidfVectorizer в сочетании с наивным байесовским классификатором. Подготовка текстов, обучение моделей, сравнение Accuracy и F1, анализ ошибок.

### PR7. Случайный лес

Сравнение дерева решений и случайного леса. Оценка качества моделей на одинаковых обучающих и тестовых данных, построение графика важности признаков.

## Структура проекта

- `PR1/` — первая практическая работа и датасет `tips.csv`.
- `PR2/` — исследовательский анализ данных и `customers_dirty.csv`.
- `PR3/` — предобработка данных и `customers_dirty.csv`.
- `PR4/` — регрессионная модель.
- `PR5/` — бинарная классификация.
- `PR6/` — классификация текстов.
- `PR7/` — дерево решений и случайный лес.
- `make_pr6.py` — скрипт создания ноутбука PR6.
- `make_pr7.py` — скрипт создания ноутбука PR7.

В практических папках находятся ноутбуки `notebook.ipynb`, а также дополнительные файлы с данными и описанием, если они необходимы для конкретной работы.

## Как запустить проект

1. Установить Python.
2. Установить необходимые библиотеки.
3. Открыть нужный файл `notebook.ipynb` в Jupyter Notebook или VS Code.
4. Запустить ячейки ноутбука по порядку.
5. Проверить результаты, таблицы, графики и выводы.

Установка основных библиотек:

```bash
pip install pandas numpy matplotlib scikit-learn jupyter nbformat
```
