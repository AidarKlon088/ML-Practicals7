## О проекте

Этот репозиторий содержит 7 практических работ по машинному обучению на Python.

В практических работах PR1–PR5 и PR7 используется Spotify Tracks Dataset. В PR6 применяется SMS Spam Dataset для классификации текстов.

В проекте рассматриваются анализ данных, предобработка, регрессия, классификация и ансамблевые методы машинного обучения.

## Используемые технологии

- **Python** — язык программирования.
- **Jupyter Notebook** — выполнение и документирование экспериментов.
- **Pandas, NumPy** — обработка и анализ данных.
- **Matplotlib, Seaborn** — визуализация данных.
- **Scikit-learn** — предобработка, обучение и оценка моделей.

## Содержание практических работ

### PR1. Настройка окружения и знакомство с данными

Загрузка Spotify Dataset, изучение структуры таблицы, типов данных и пропусков. Построение первых графиков и формулирование наблюдений.

### PR2. Исследовательский анализ данных (EDA)

Анализ Spotify Dataset: распределения признаков, выбросы, частоты жанров, корреляции и связи между характеристиками музыки.

### PR3. Предобработка данных

Подготовка данных с использованием `Pipeline` и `ColumnTransformer`.

- Заполнение числовых пропусков через `SimpleImputer`.
- Масштабирование с помощью `StandardScaler`.
- Кодирование музыкальных жанров через `OneHotEncoder`.
- Разделение данных на Train/Test без утечки информации.

### PR4. Линейная регрессия

Прогнозирование популярности треков Spotify на основе музыкальных характеристик.

Обучение `LinearRegression`, оценка MAE, RMSE и R², анализ корреляций и сравнение наборов признаков.

### PR5. Бинарная классификация

Определение популярных и непопулярных треков с помощью `LogisticRegression`.

Оценка Accuracy, Precision, Recall и F1. Построение матрицы ошибок и интерпретация результатов.

### PR6. Классификация текстов

Определение спам-сообщений с помощью наивного байесовского классификатора `MultinomialNB`.

Сравнение двух способов векторизации текста:

- `CountVectorizer`
- `TfidfVectorizer`

Оценка Accuracy и F1, анализ ошибок классификации.

### PR7. Случайный лес

Сравнение `DecisionTreeClassifier` и `RandomForestClassifier` на Spotify Dataset.

Обучение случайного леса из 100 деревьев, сравнение Accuracy и F1, анализ важности признаков (`feature_importances_`).

## Как запустить

**1.** Установить Python 3.11 или новее.

**2.** Установить необходимые библиотеки:

```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn jupyter nbformat
```

**3.** Открыть репозиторий в VS Code или Jupyter Notebook.

**4.** Открыть нужный файл `notebook.ipynb`.

**5.** Выбрать Python Kernel и выполнить все ячейки через **Restart & Run All**.

Для PR1–PR5 и PR7 используется `PR1/dataset.csv`, для PR6 — `PR6/spam.csv`.
