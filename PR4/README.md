# Практическая работа №4 — Линейная регрессия

**Тема:** Прогнозирование популярности музыкальных треков  
**Язык:** Python  
**Библиотеки:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## О проекте

В этой работе я использовал Spotify Dataset, чтобы построить модель, предсказывающую популярность музыки по её характеристикам.

## Основной код

| Код | Что делает |
|---|---|
| `train_test_split()` | Делит данные на обучающую и тестовую части |
| `SimpleImputer()` | Заполняет пропущенные значения |
| `StandardScaler()` | Масштабирует признаки |
| `LinearRegression()` | Обучает модель регрессии |
| `model.predict()` | Предсказывает популярность |
| `mean_absolute_error()` | Считает среднюю ошибку |
| `mean_squared_error()` | Используется для расчёта RMSE |
| `r2_score()` | Оценивает качество регрессии |
| `df.corr()` | Помогает найти коррелирующие признаки |

## Что я сделал

Обучил линейную регрессию на характеристиках треков, проверил корреляции, сравнил наборы признаков и построил графики ошибок модели.

## Запуск

1. Установить библиотеки: `pip install pandas numpy matplotlib seaborn scikit-learn jupyter`
2. Открыть `notebook.ipynb`.
3. Выбрать Python Kernel и нажать **Run All**.

Используется датасет `PR1/dataset.csv`.
