# Практическая работа № 6. Классификация текстов

Выполнил: Айдар Нурбекович

Цель: сравнить CountVectorizer и TfidfVectorizer для классификации текстов с помощью наивного байесовского классификатора.

В работе выполняются очистка текста, разделение на train/test, векторизация, обучение двух моделей, сравнение Accuracy и F1, анализ ошибок.
