# Практическая работа №7

## Тема
Межпроцессное взаимодействие в Linux: каналы, сигналы и конвейеры.

## Цель
Изучить взаимодействие процессов через Pipe, обработку сигналов и создание конвейеров.

## 1. pipe_demo.py
**Запуск:** `python3 pipe_demo.py`

**Результат:**
```
Родитель получил: Привет от ребёнка, PID=633
```

Программа создаёт дочерний процесс с помощью `os.fork()` и передаёт сообщение через `os.pipe()`.

## 2. signal_demo.py
**Запуск:** `python3 signal_demo.py`

**Результат:**
```
Мой PID: 661
^CПолучен SIGINT, но я не завершаюсь
```

Программа обрабатывает сигнал SIGINT и не завершается при Ctrl+C. Для остановки используется SIGTERM.

## 3. pipeline.py
**Запуск:** `python3 pipeline.py`

**Ожидаемый результат:**
```
pipe_demo.py
pipeline.py
signal_demo.py
```

Программа соединяет команды `ls` и `grep py` в конвейер.

## Ответы на вопросы

**Зачем закрывать концы канала?**

Чтобы освобождать файловые дескрипторы и обеспечить правильную обработку EOF.

**Почему Ctrl+C не завершает программу?**

Потому что установлен обработчик SIGINT.

**Для чего нужен `p1.stdout.close()`?**

Чтобы закрыть родительскую копию канала вывода первого процесса и обеспечить корректную работу конвейера.

## Вывод
Изучены методы межпроцессного взаимодействия в Linux: создание процессов, обмен данными через каналы и обработка сигналов.
