## О проекте

В этой работе я использовал Spotify Dataset с [Kaggle](https://www.kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset), чтобы изучить данные о музыкальных треках.

## Основные команды

| Код | Что делает |
|---|---|
| `pd.read_csv()` | Загружает CSV-файл |
| `df.head()` | Показывает первые 5 строк |
| `df.info()` | Показывает типы данных и количество заполненных значений |
| `df.describe()` | Выводит статистику числовых столбцов |
| `df.isnull().sum()` | Проверяет количество пропусков |
| `df.shape` | Показывает количество строк и столбцов |
| `value_counts()` | Подсчитывает количество записей в категориях |
| `plt.hist()` | Строит гистограмму |

## Визуализация

В `notebook.ipynb` я построил два графика:

- **Популярность треков** — распределение значений `popularity`.
- **Музыкальные жанры** — количество треков по жанрам `track_genre`.

## Как запустить
